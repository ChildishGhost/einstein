# RFC 0007：啟動器視覺設計

## 摘要
記錄 `db39f26` 時啟動器的版面與外觀：單一個緊湊的欄位——輸入框在上、結果在下——並依內容調整大小，採用單一深色主題與 CJK 優先的字體。行為見 [RFC 0004](0004-launcher-and-search.md)。

## 動機
將視覺與行為分開，外觀就能變更而不動到啟動器的行為，反之亦然。

## 需求

### 版面
- **R1** — 單一欄位：輸入框在上，結果清單緊接在其下；輸入為空時不顯示清單（RFC-0004/R4）。
- **R2** — 視窗寬 600 px；高度跟隨內容，因此只有輸入框時會縮小、有結果時會增高（有動畫的調整大小，寬度不變；RFC-0002/R16）。
- **R3** — 結果列左側顯示選用的正方形圖示，旁邊是標題、其下為描述；每段文字都只佔一行，以省略號截斷。
- **R4** — 選取的列以半透明的淺色背景反白。
- **R5** — 沒有視窗邊框、沒有捲軸，文字不可選取。

### 外觀
- **R6** — 單一深色主題：視窗背景 `#333`；輸入文字為白色、24 pt，無邊框且背景透明；標題 20 px `#eee`；描述 14 px `#999`；圖示 36×36 px；選取色 `rgba(255, 255, 255, .3)`。
- **R7** — 文字使用 CJK 優先的字體組：Noto Sans CJK TC、LiHei Pro，最後是系統 UI 字型。

## 設計
- 高度在每次結果變更後與顯示前於 renderer 中量測，再由主行程套用（RFC-0004/R1、RFC-0002/R16）。
- 樣式位於 Vue 元件與 `src/omniSearch/index.scss`。

### `db39f26` 時已知的缺口（非決策）
- 沒有淺色主題，也沒有 `prefers-color-scheme`；顏色寫死。
- 輸入框沒有 placeholder；視窗不透明、直角、沒有模糊效果。
- 圖示沒有 alt 文字；描述文字（`#333` 上的 `#999`）的對比度低於小字的 WCAG AA 標準。

## 驗證
追溯式（RFC-0001/R16）：描述 `db39f26` 時的程式碼；不受測試覆蓋檢查約束。之後變更這些需求的 RFC，須在「與較早 RFC 的關係」中列出。
